# Changelog

## 0.1.0 - 2026-10-09

First public early release for Windows 11 x86-64.

- Inspect developer disk usage, projects and installed PATH tools.
- Review storage evidence and create confirmed, revalidated cleanup plans.
- Save a working project snapshot and compare later observations.
- Use a local SQLite database shared by the desktop app and CLI.
- Browse compact tables with resizable, saved columns and evidence inspectors.
- Choose light, dark or system appearance; navigate with the keyboard and zoom.
- Install with the per-user Windows installer or build from source.

The release is unsigned. Compatibility checks and scope limits are documented
in [STATUS.md](STATUS.md).
