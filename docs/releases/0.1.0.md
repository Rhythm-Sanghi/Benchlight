Benchlight 0.1.0 is the first early release for Windows 11 x86-64.

Inspect developer disk usage, review installed PATH tools, and compare a project
with a saved working snapshot. Everything runs locally. Scans and cleanup start
only when you ask.

## Install

Download `Benchlight_0.1.0_x64-setup.exe` below. The per-user installer expects
WebView2 to be installed and preserves your database when uninstalled. This
release is unsigned.

The standalone desktop and CLI executables are also provided. Use the installer
for the complete setup. The matching source archive and SHA-256 checksums are
attached; source is licensed under GPL-3.0-or-later.

## Verification

The recorded 0.1.0 development checks reported 38 Rust tests, 20 frontend tests,
80 text-contrast checks, formatting, lint/type checking and a production build.
These counts describe that release baseline; use the current workflow run for
later revisions.

The release workflow runs formatting, Clippy, Rust tests, frontend lint and type
checks, frontend tests and 80 text-contrast checks before building and publishing.
Local review also covered native navigation, both themes, the 800 px layout,
200% zoom, scan/snapshot flows and keyboard focus. Installer lifecycle and cleanup
were tested with temporary fixtures.

Different-version upgrades, spoken screen-reader output, global Windows text
scaling, and live OneDrive/removable-drive sessions still need broader testing.
Logical sizes are not guaranteed recovered space. Read the
[cleanup and recovery guide](https://github.com/Rhythm-Sanghi/Benchlight/blob/main/docs/cleanup.md)
before recycling data.

See the [README](https://github.com/Rhythm-Sanghi/Benchlight#readme) and
[project status](https://github.com/Rhythm-Sanghi/Benchlight/blob/main/STATUS.md)
for setup and limitations. Report vulnerabilities
[privately](https://github.com/Rhythm-Sanghi/Benchlight/security/advisories/new).
