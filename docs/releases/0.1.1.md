Benchlight 0.1.1 is a local Windows release candidate. It is not published.

This candidate tightens scan-completeness checks for directories that change
while being measured. It preserves cleanup recovery names through ambiguous
Windows Shell failures, pairs cleanup state and log writes in SQLite
transactions, and adds deliberate removal of older working-state records while
retaining the latest baseline. The source archive is built from an exact commit
and accompanied by a commit/tree/hash manifest.

Cleanup still requires a complete eligible measurement, revalidation and exact
`RECYCLE <plan number>` confirmation. It uses the Windows Recycle Bin and has
no permanent-delete fallback. Logical sizes are not guaranteed disk savings.

This candidate remains unsigned and requires WebView2. The published 0.1.0
release and its historical verification record remain unchanged. Review the
local qualification report before any decision to tag or publish 0.1.1.
